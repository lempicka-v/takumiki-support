## 更新手順

1. この作品の公式素材であること、紹介用に加工された画像か実機画面か、対象バージョン／開発段階を確認します。不明な項目は不明のまま記録し、最新開発版と断定しないでください。
2. 最適化したWebPまたはJPEGを `assets/images/` に追加します。工芸SVGを個別機体画像に置き換える場合も、確認したローカル画像へ参照を変更できます。外部URLへの直リンクは使いません。
3. `index.html` の該当する `<img>` の `src`、`alt`、`<figcaption>` を更新します。ギャラリーは拡大先の `<a href>` も同じ画像へ変更してください。メイン画像を変更する際は `og:image` の絶対URLと `og:image:alt` も見直します。
4. `width`・`height` とCSSの `aspect-ratio` を実寸と一致させ、表示時のレイアウト移動を防ぎます。同じ枠への差し替えでは現行比率を保ってください。紹介画像は598:1300、機体意匠は5:4、背景装飾は4:3です。
5. メインビジュアルはCSSで紹介画像の一部を切り出しています。画像変更時は `assets/showcase.css` の表示位置を見直してください。ギャラリーでは画像全体を表示し、宣伝見出しやUIを切り落とさないでください。
6. スマートフォンとデスクトップで、画像の切り抜き位置・文字・欠損・容量を確認します。スマートフォンの横スクロール、拡大リンク、アイコンも確認してください。

`alt` は「画像」のような汎用語ではなく、「App Store掲載の戦闘紹介画像」など、素材の種類と確認できる見た目を簡潔に説明してください。機体名が不明なときは推測しません。周辺の文章と重複するだけの装飾画像は、用途を確認して空の `alt` を使えます。

## キャプションの扱い

- 工芸意匠や新たなコンセプトアートには、**実際のゲーム画面ではない**ことを引き続き明記します。
- 現在の公式画像は「App Store掲載の紹介画像」として案内します。宣伝用画像を「実機検証済みスクリーンショット」「最新ビルドの画面」と呼ばないでください。
- 実ゲームの画面と確認できた素材に差し替えた箇所だけ、この説明を外せます。
- 開発中の画面・モデルは「開発中の画面」「開発中の機体モデル」と明示します。既存配信版の画像と混在させないでください。
- 海外工芸・半導体機の画像が追加されても、それだけで実装済みの機体として紹介しないでください。
- 動画がない段階で、再生できない「ムービーを見る」ボタンを設置しないでください。

素材更新時は [content-sources.md](content-sources.md) に確認日、素材の提供元、対象バージョンを追記します。ゲームの仕様も変更する場合は、サポート・プライバシーとの整合性を確認してください。
